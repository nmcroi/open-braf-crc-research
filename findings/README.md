# Bevindingenregister / findings register

This structured view links original reviewed reports and primary sources for the Dutch dashboard. It does not replace GitHub Issues or source records. Add one stable ID per substantive change; preserve history through Git. Every entry needs summary, meaning, limitations, next step, review status, report URL and source locators. Unknown access and reviews remain explicitly unknown. Cohort IDs identify known dependencies, not inferred patient independence. No private notes or medical dossier here. Register schema_version 1.
