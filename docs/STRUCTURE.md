# Project map

GitHub Issues: authoritative public tasks and states. Discussions: onboarding and questions. Pull requests: reviewed changes. The private Obsidian workspace: Dutch owner overview, private tasks and references to existing work. The local agent mailbox: coordination only.

`sources/` holds catalog and curated source records; `datasets/` dataset provenance; `claims/` atomic statements; `hypotheses/` testable connections; `analyses/` runnable methods; `results/` permitted aggregates; `reviews/` independent checks; `docs/` workflow and synthesis.

A typical chain is Issue → hypothesis → claim → primary source or dataset → analysis → independent review → revised synthesis. Work can end with a useful negative result. Broadening beyond BRAF/MSS requires a stated biological connection and a transferability check.
