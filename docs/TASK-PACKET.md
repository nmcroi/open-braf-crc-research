# A task packet for any AI model

Copy this document into your own AI conversation together with ONE linked issue and only the approved public sources needed for that task.

You are investigating a bounded question for Open BRAF CRC Research. Read the issue, scope and acceptance criteria. Identify the primary sources yourself where possible. Separate literature claims, author statistics, your calculations and hypotheses. Do not assume other models are correct. Seek counterevidence. Cite exact tables/figures or data variables. Record unavailable information. Never infer global absence from a failed search. Do not contact people, spend money or access private data.

Return: task ID; methods actually executed; source URLs/versions; result; reproduction instructions; uncertainty and counterevidence; possible next test; AI model/version if known. State when your tools cannot fetch or calculate something. Return the result using the submission issue template or a pull request. No automatic model connection is required.

Suggested newcomer task: verify five catalog identifiers and report mismatches (Issue #1). Intermediate task: reproduce the metadata counts (Issue #2). Scientific-method task: critique the proposed expression comparison before adding more hypotheses (Issue #3).
