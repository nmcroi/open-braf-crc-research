# Data and publication boundaries

Public repository: source identifiers/links, original methods and notes, shareable code and permitted aggregate outputs. No patient dossier, private conversations, unrestricted folder mirrors or restricted sequencing data. A personally motivated project does not authorize publishing personal history.

Full texts remain at the publisher or authorized repository unless redistribution permission is documented for that specific object. A public API is not a universal redistribution license. Restricted datasets are never loaded into model context. Locally authorized processing is a separate process; only outputs explicitly permitted by its agreement can be considered for sharing. Aggregation alone does not confer permission.

A maintainer reviews the staged file list and content before publication. Automated scans are supplemental; they cannot prove de-identification or legal rights. Dataset rights are recorded per object. Corrections remain traceable; licensing does not relicense upstream works.
