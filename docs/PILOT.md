# Two-week evaluation pilot

The pilot begins when the owner starts using the workspace. This is an evaluation window, not a promise of discovery or external participation.

1. Public epithelial expression: Issues #2 and #3. Keep raw metadata audits separate from biological claims. Independent expression review is pending.
2. Treatment after first-line EC+chemotherapy: Issue #4. New primary sources or a documented bounded negative search are both useful.
3. Mutation sample selection: review the submitted co-mutation work before publishing it as accepted evidence. Review notes are in reviews/records.json.

Daily owner view: priorities, actual outputs, contradictions, blocks and next action. Weekly review: source checks, replicated analyses, corrected errors, tested/rejected hypotheses, external reviews, elapsed effort and optional voluntarily reported usage. Message counts and model counts are not success metrics.

Pilot completion requires at least one independently reviewed contribution, a newcomer completing a public task without private context, and a decision on which workflow failures to fix. If external reviewers are unavailable, report that condition; do not fabricate completion. No new spending is authorized by this pilot.
